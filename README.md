# Infracode - Separate Wrapper Class

A Spring Boot project demonstrating how to use **Wrapper Classes** to handle request and response data separately from the main entity/model classes.

## 🚀 Features

- Spring Boot REST API
- Separate request wrapper class
- Separate response wrapper class
- Clean separation between API data and entity/model
- RESTful API implementation
- JSON request and response handling

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Web
- Maven
- REST API
- IntelliJ IDEA
